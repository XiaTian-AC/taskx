# tkx v1 实现计划

> **执行方式：** executing-plans，逐 task 执行，每个 task 完成后验证 + commit。

**目标：** 构建 `tkx`——单二进制 Lua 任务运行器，支持 global Taskfile + 参数传入 + 后台任务管理（bstart/ls-running/watch/stop）。

**架构：** Go + gopher-lua 单二进制、可重入、无守护进程。前台直接执行；后台 = bstart 派生 detached 子进程 `tkx _run <name>`，输出写日志文件，状态存 run.json。平台差异用 build tags 隔离。

**技术栈：** Go 1.22+，唯一第三方依赖 gopher-lua v1.1.1，其余全标准库。

## 全局约束

- 仓库根 `F:\Workspace\Project\tastx`；module 名 `tkx`；二进制名 `tkx`
- 配置 `$XDG_CONFIG_HOME/taskx/`（默认 `~/.config/taskx`）→ `Taskfile.lua` + `config.lua`
- 数据 `$XDG_DATA_HOME/taskx/`（默认 `~/.local/share/taskx`）→ `run.json` + `logs/<name>#<N>.log`
- 保留内建子命令：`ls` `start` `run` `bstart` `ls-running` `watch` `stop` `help` `version` `_run`
- `--shell` 为 CLI 保留 flag
- 默认 shell：Windows → `pwsh -NoProfile -Command`；Unix → `bash -euo pipefail -c`；sh → `-e -c`；自定义 → `-c`
- 退出码：0 成功，1 任务失败，2 用法错误
- GitHub 需代理：`$env:HTTP_PROXY="http://127.0.0.1:7890"; $env:HTTPS_PROXY="http://127.0.0.1:7890"` 后 `go get`
- 实现文件中不加注释

## Task 3：shell 包

**文件：** `internal/shell/shell.go` + `shell_windows.go` + `shell_unix.go` + 测试

**核心结构：**
```go
type Spec struct { Path string; Args []string }
func (s Spec) Argv(cmd string) []string  // append(Args, cmd)
func Resolve(name string, registry map[string]string) (Spec, error)
```

**argsFor 按名字分类：** pwsh → `[-NoProfile, -Command]`；bash → `[-euo, pipefail, -c]`；sh → `[-e, -c]`；自定义 → `[-c]`。

**Resolve 逻辑：** name="" → 按 GOOS 选默认（win=pwsh, unix=bash）；registry 有则用 registry 的 path + argsFor(name)；否则 resolveBuiltin。

**Windows git bash 探测链（shell_windows.go）：**
1. `where.exe git` → 取首行 → `filepath.Dir(filepath.Dir(gitExe))` = git 安装根 → `<root>/bin/bash.exe`
2. 常见路径 fallback：Program Files/Git、LOCALAPPDATA/Programs/Git、scoop（`~/scoop/apps/git/current/bin/bash.exe` + `$SCOOP/apps/git/current/bin/bash.exe`）
3. 都找不到 → error 提示在 config.lua 注册

**提示：** whereGit / fileExists 做成包级 var 以便测试注入。Unix 用 exec.LookPath。

**测试：** argsFor 纯函数、registry 覆盖、未知 shell 报错。

## Task 4：argparse 包

**文件：** `internal/argparse/argparse.go` + 测试

**核心结构：**
```go
type Parsed struct { Flags map[string]any; Positional []string }
type Spec struct { Type string; Required bool; Desc string }
func Parse(argv []string, specs map[string]Spec) (*Parsed, error)
func ToLuaTable(L *lua.LState, p *Parsed) *lua.LTable  // flags → 字段，positional → args._
```

**Parse 两种模式：**
- specs==nil（heuristic）：`--name value` → string，`--name` → bool true，`--` → 余下全 positional
- specs!=nil（strict）：bool 永不消费下一个 token；string 必须有值否则报错；未知 flag 报错；`--name=value` 也支持；required 校验

**提示：** `--name=value` 中 bool 类型只接受 true/false。Validate 做 required + 类型强制。ToLuaTable 中 positional 放 `args._`（LTable 数组，1-indexed）。

**测试：** heuristic 模式、strict 模式（string/bool/required/unknown）、`--` 分隔符、`=` 形式、ToLuaTable。

## Task 5：taskfile 包

**文件：** `internal/taskfile/taskfile.go` + 测试

**核心结构：**
```go
type ArgSpec struct { Type string; Required bool; Desc string }
type Task struct { Name, Desc string; Fn *lua.LFunction; Args map[string]ArgSpec } // Args==nil 表示未声明
type File struct { L *lua.LState; Tasks map[string]*Task; Order []string }
func Load(path string) (*File, error)
func (f *File) Close()
func (f *File) Get(name string) (*Task, bool)
```

**Load 逻辑：** DoFile → 返回值必须是 LTable → ForEach 遍历：
- value 是 LFunction → 简单任务
- value 是 LTable → 取 `desc`（string）、`args`（表，每个 key → ArgSpec）、`run`（LFunction，必须存在否则跳过+warning）
- 名字不符 `^[A-Za-z0-9][A-Za-z0-9_-]*$` → 跳过+warning
- Order 排序（sort.Strings）保证 ls 输出稳定

**提示：** gopher-lua 的 `RawGetString` / `ForEach` / `RawGetInt` 等 API。LState 要保活（File 持有），Close 时释放。

**测试：** function/table 两种形式、desc/args 提取、缺失文件、语法错误、无返回值、空表、Order 排序。

## Task 6：runtime 包

**文件：** `internal/runtime/ctx.go` + `runner.go` + 测试

**核心：** ctx 是 Lua userdata，metatable 设 `__index` 指向方法表。每个方法 `L.CheckUserData(1).Value.(*Ctx)` 取回 Go 结构。

```go
type Ctx struct {
    L *lua.LState; File *taskfile.File; ShellName string; Registry map[string]string
    Stdout, Stderr io.Writer; Stdin io.Reader; Background bool
    reader *bufio.Reader  // ask 用，惰性初始化
}
type Options struct { ShellName string; Registry map[string]string; Stdout, Stderr io.Writer; Stdin io.Reader; Background bool }
func Run(f *taskfile.File, name string, args *lua.LTable, opts Options) error
```

**ctx 方法：**
- `ctx:sh(cmd, opts?)` — shell.Resolve → exec.Command → Stdout/Stderr 继承；interactive 时 Stdin 也继承；非零退出 → `L.RaiseError("command failed (exit %d): %s", code, cmd)`
- `ctx:run(name, args?)` — 查 file.Tasks → callTask（PCall）
- `ctx:echo(...)` — join with space → Fprintln(Stdout)
- `ctx:ask(prompt, default?)` — Background 或 Stdin==nil → 返回 default；否则 bufio.ReadLine
- `ctx:env(name)` / `ctx:cwd()` / `ctx:os()`

**callTask：** push fn → push ctxUD → push argsTable → `L.PCall(2, 0, nil)`

**Run：** 查 task → callTask → error 格式化 `task %q: %v`

**提示：** 每次调用 newCtxUserData 创建新 userdata + metatable。exec 命令的 Stdout/Stderr 从 Ctx 取（前台=os.Stdx，后台=日志文件）。测试用 `echo` 命令跨平台兼容（pwsh/bash 都有 echo）。

**测试：** echo、sh（echo from-shell）、sh fail（exit 3）、chain（ctx:run）、env/os、task not found。

**文件：** `internal/bg/` 下 registry.go / launcher.go / launcher_windows.go / launcher_unix.go / procs_windows.go / procs_unix.go / watch.go + 测试

这是一个完整 package，一次实现 + 测试。

### 7a. registry.go — run.json 管理

```go
type Instance struct {
    ID, Name string; N, PID int; Args []string; CWD, Log string
    Started time.Time; Status string; ExitCode int; EndedAt *time.Time
}
func NextID(dataDir, name string) (id string, n int, err error) // counter++ 持久化
func Register(dataDir string, inst Instance) error              // 追加 + 轮转同 name 已退出实例（删日志）
func MarkEnded(dataDir, id, status string, code int) error
func Snapshot(dataDir string) ([]Instance, error)
func Running(dataDir, name string) ([]Instance, error)
```

**提示：** 文件锁用 `O_CREATE|O_EXCL` lockfile + stale 检测（>10s 强占）+ 5s 超时。save 用 temp+rename 原子写。Register 里轮转：同 name 且 status!="running" 的实例 → 删其 Log 文件 → 从列表移除。

### 7b. launcher.go — detached 派生

```go
type StartOptions struct { SelfPath, TaskName, ShellName, CWD, DataDir string; TaskArgs []string }
func Start(opts StartOptions) (*Instance, error)
func buildRunArgv(taskName, shellName, id string, taskArgs []string) []string
// → ["_run", taskName, ("--shell", shellName)?, "--id", id, "--", taskArgs...]
```

**Start 流程：** NextID → 建 log 文件（O_CREATE|O_TRUNC）→ exec.Command(self, argv...) → cmd.Stdout/Stderr = logFile → detach(cmd) → Start → Release → Register。

**detach 平台差异：**
- Windows：`SysProcAttr{CreationFlags: 0x00000008 | 0x00000200}`（DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP）
- Unix：`SysProcAttr{Setsid: true}`

### 7c. procs — 存活检测 + 杀进程树

**Windows：** Alive 用 `tasklist /FI "PID eq N" /FO CSV /NH`，检查输出含 `"N"`（引号界定避免子串误匹配）。Stop 用 `taskkill /PID N /T /F`（先 Alive 检查，已死则跳过）。

**Unix：** Alive 用 `syscall.Kill(pid, 0)`。Stop 用 `Kill(-pid, SIGTERM)` → 轮询 5s → `Kill(-pid, SIGKILL)`（setsid 使 pgid==pid）。

### 7d. watch.go — 日志 tail

```go
func Watch(logPath, id string, isAlive func() bool, out io.Writer) error
```

**逻辑：** 打开文件 → 打印 header → drain 全量 → 循环：检查 SIGINT（signal.Notify）→ 检查文件增长（stat size > offset → drain）/ truncation（size < offset → seek 0, offset=0）→ isAlive false → 最终 drain + 打印 exited → 返回。poll 200ms。

**提示：** drain 用 ReadAt(offset) 循环直到 n==0 或 err。Ctrl+C 只杀 watch 进程，后台任务在另一个 session/pgroup 不受影响。

**测试：** helper process 模式测 Alive/Stop（TestHelperProcess + GO_WANT_HELPER_PROCESS=1）；buildRunArgv 纯函数；Watch 用临时文件 + goroutine + isAlive 翻转测 follow/truncation/missing。

### cli.go — 全命令分发

```go
type Deps struct { SelfPath string; Version string; Stdin io.Reader; Stdout, Stderr io.Writer }
func Run(argv []string, d Deps) int
```

**分发：** help/version/ls/start/run/bstart/ls-running/watch/stop/_run → 各 cmd 函数；default → cmdRunTask（当任务名处理）。

**关键函数：**
- `extractShell(argv) (name string, rest []string)` — 扫描 `--shell` / `--shell=`，移除后返回剩余
- `confirm(prompt, in, out) bool` — 读一行，y/yes → true
- `findInstance(all, ref) (*Instance, error)` — 含 `#` → 精确匹配；否则 → 同 name 最新（N 最大）
- `loadTaskfile(d) (*File, map[string]string, error)` — ConfigDir → Shells → TaskfilePath → Load

**cmdBstart 流程：** extractShell → loadTaskfile → 查 task → Parse 校验 → EnsureDataDir → Running(dataDir, name) → 有则打印警告+列表+confirm → bg.Start → 打印 started/log/watch/stop 提示。

**cmdInternalRun 流程：** 解析 `_run <name> [--shell s] [--id id] -- [args]`（也读 TKX_SHELL/TKX_INSTANCE_ID/TKX_CWD 环境变量）→ Chdir(cwd) → loadTaskfile → Parse → runtime.Run(Background=true) → MarkEnded → 返回 exitCode。

**cmdStop 流程：** ref 含 `#` → 精确停一个；否则 → 同 name 所有 running 实例，>1 时 confirm → 逐个 Stop + MarkEnded("stopped", -1)。

**cmdWatch 流程：** findInstance → isAlive = `inst.Status=="running" && bg.Alive(pid)` → bg.Watch。

**cmdLsRunning 流程：** Snapshot → 按 Started 降序 → 逐行：ID/pid/status/age/cwd。running 但 !Alive → 显示 "dead"；exited 且 ExitCode!=0 → "exited(N)"。

**main.go 改写：** `os.Exit(cli.Run(os.Args[1:], cli.Deps{Version: version, Stdin: os.Stdin, Stdout: os.Stdout, Stderr: os.Stderr}))`
